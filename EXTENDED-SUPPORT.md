# Extended Support

## Extended Support Policy

Extended support is not currently offered for this project.

The repository contains static research artifacts. Maintainers may update
the materials for correctness, clarity, reproducibility, or compatibility
with the related publication, but older artifact versions are not
maintained as independent long-term support branches unless explicitly
documented in a future release.

## Version Archival

Published releases should remain available through GitHub releases and
tags. Consumers who require exact reproducibility should pin to a release
tag rather than the default branch.
