# Support

## Support Policy

This project is maintained on a best-effort basis by the project
maintainers.

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest release | No |
| Older releases | No |

Corrections are applied to the latest release. Older versions may remain
available for reproducibility but are not patched or maintained.

## Reporting Issues

Use GitHub issues to report:

- Incorrect or ambiguous prompt text.
- Invalid JSONL records.
- Documentation gaps.
- Reproducibility issues related to the supplementary files.

Do not include private data, credentials, or sensitive user information in
issues or pull requests.
