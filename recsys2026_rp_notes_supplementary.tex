\section{Evaluation Prompt Templates}
\label{app:prompts}

The complete LLM-as-judge prompt templates for all 21 metrics in the
SERA taxonomy (Table~1 of the main paper) are provided as individual
text files in the accompanying \texttt{metric\_prompts/} folder.
Each file contains the full rubric prompt provided to a GPT-4o judge
alongside the conversation context.  Seed-query datasets
(JSONL format) are included under
\texttt{seed\_datasets/}.

Table~\ref{tab:prompt-index} lists every metric with its scoring type
and corresponding prompt file.
